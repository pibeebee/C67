# Journey Showcase execution report — 6 November 2026

## Delivered behavior

C67 Journey is a separate app with bundle ID `com.hendra.pocjourney.showcase`, an iOS 26 minimum, and a guided Indonesian UI. It covers trip setup, optional preferences, sourced place selection, mandatory places, branch review, calculation, map/timeline review, detailed TransJakarta journeys, save/reopen, +30-minute proposals, rejection and Markdown/JSON export.

Demo and Live use separate local storage. Demo is the default in both build configurations and retains the dated synthetic provider evidence. Live uses the existing native providers and preference/routing pipeline. A debug-only explicit provider-check launch uses separate evaluation storage.

## Shared implementation and provenance

The app consumes the existing Trip Integration package. Recommendation, hours, weather, routing objectives, audit and acceptance remain in the shared engine. The explicit Blok M authored provider factory is now available in both configurations for the new app's Demo choice. Existing legacy replay entry points stay Debug-only.

The geometry sidecar contains 18 GTFS patterns and 4,366 vertices from the same published ZIP used by the corridor-1 routing snapshot. ZIP SHA256 is `376b11f72ac30f9f4eb972ae32c7f1a3251b416dc3cd77cc573475a3b2676b9c`. Ordered stop-to-shape projection is bounded to 150 m, preserving repeated stop occurrences. The map draws only the selected bus segment. Walking connections are labeled indicative, and geometry availability never changes travel-time evidence. Gabarito is bundled from Google Fonts with SIL OFL 1.1. Semantic surfaces and Dynamic Type complement C67's Royal Blue accent. [Font source](https://github.com/google/fonts/tree/main/ofl/gabarito)

## Verification

Verification is in progress. Raw outputs are retained under the ignored `poc-journey/.verification/journey-showcase-20261106/` directory.

## Failures and corrections

Initial testing found that the full-width primary button's empty label area did not receive taps. The entire visible surface now has a rectangular content shape, including the draft-resume control. The first font build copied the font but omitted the UIAppFonts registration through generated build settings. An explicit generated Info.plist now registers the font, and the targeted registration check passed.

The initial automatic map camera started at an inappropriate region. The initial camera now starts around Jakarta before fitting the route. Interactive maps embedded in the scrolling itinerary also captured vertical swipes. Preview maps now allow scrolling through the page, and a separate full-screen map provides interaction.

Failed and interrupted result bundles are retained alongside later runs. Passing claims use the final relevant results.

## Limits

The experience covers a one-day Blok M trip from and back to Bundaran HI, with car/taxi or direct corridor-1 TJ plus walking. Real bus positions, transfers, fares, field entrance/accessibility and observed arrival accuracy remain outside this experiment. Human recommendation relevance and manual VoiceOver operation need separate observations. Simulator rendering and tests are recorded independently of signed-device provider results.
