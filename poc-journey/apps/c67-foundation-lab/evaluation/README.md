# English evaluation set v1

24 new cases, six per capability; three repetitions each. All venue details are synthetic.
The model receives a single input case; oracle.json is read only by the external assessor.
This set is authored and inspected during implementation, so it is not a blind holdout.
Freeze source, prompts, input and oracle hashes before the final series.
Greedy repetitions are correlated. Automated checks cover shape, references and selected objective conditions, not complete semantic quality.
Two independent human reviews remain required for factual claims and recommendation quality.
